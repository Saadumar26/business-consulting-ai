# 💼 AI Business Consulting Team

A multi-agent business consulting system built with CrewAI, Groq, and Streamlit.

The system uses multiple specialized AI agents to analyze a business and produce a structured business strategy report.

## 🤖 AI Consulting Team

The system contains five specialized agents:

1. Market Research Analyst
2. Customer & Competitor Analyst
3. Business & SWOT Analyst
4. Strategy Consultant
5. Senior Report Writer

## 🔄 Workflow

Business Information
        ↓
Market Research
        ↓
Customer & Competitor Analysis
        ↓
Business & SWOT Analysis
        ↓
Strategy Development
        ↓
Final Consulting Report

## 🛠️ Technologies

- CrewAI
- Groq
- GPT-OSS 120B
- Streamlit
- Python

## ✨ Features

- Multi-agent business analysis
- Market analysis
- Customer analysis
- Competitor analysis
- SWOT analysis
- Business strategy
- Go-to-market strategy
- Marketing strategy
- 30-day action plan
- 90-day action plan
- Long-term strategy
- Downloadable Markdown report

## 🔐 API Key

The application requires a Groq API key.

The API key should never be committed to GitHub.

For Streamlit deployment, add the key through Streamlit Secrets:

GROQ_API_KEY = "your_api_key"

## 🚀 Deployment

This project is designed to be deployed using Streamlit Community Cloud.

No local installation is required.

## ⚠️ Disclaimer

The generated strategy is AI-generated and should be validated using real market, customer, competitor, legal, and financial information before making important business decisions.
